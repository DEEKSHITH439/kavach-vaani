# Kavach Vaani – Quality Assurance Test Plan

**Scope:** Build, Unit Logic, Multilingual Consistency, Voice Integration, and Privacy Audits.  

---

## 1. Test Categories
1. **Build & Typecheck:** Compilation via Vite and TypeScript checking.
2. **Multilingual Content Coverage:** Verification of all 4 core scripts across English, Kannada, Hindi, Tamil, and Bengali.
3. **Mutual Exclusion & Audio Safety:** Verification of mic-speaker coordination.
4. **Indic Canvas PDF Integrity:** Rendering verification for Indic fonts.
5. **Privacy Gate & Reset Purge:** Verification of consent workflow and data clearing.
