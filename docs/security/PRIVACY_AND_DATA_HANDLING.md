# Kavach Vaani – Privacy and Data Handling Policy

**Review Date:** 27 November 2026  
**Compliance Standard:** DPDP Act 2023 Principles (Purpose Limitation, Data Minimization, Storage Limitation)  

---

## 1. Purpose Limitation
Kavach Vaani collects user responses solely to determine preliminary scheme eligibility and populate a simulated demonstration application slip. User data is never used for advertising, profiling, or unauthorized secondary purposes.

---

## 2. Explicit Consent Mechanism (Step 3)
Before collecting any personal identification information (Name, Contact, CoV/LoR status, or partial identifiers), the application pauses and presents an explicit privacy notice:
- **Audio & Visual Notice:** Explains why the details are needed.
- **Affirmative Consent:** The user must explicitly confirm with *"Yes, I agree"* / *"हाँ, सहमत हूँ"* before questions begin.
- **Right to Discontinue:** The user can click *"Decline / Stop"* or say *"No"* at any point to terminate the interaction.

---

## 3. Data Minimization
- **Name:** Captured only for application reference preview.
- **Contact:** 10-digit mobile number for notification simulation.
- **Aadhaar:** Strictly limited to the **last 4 digits**. Full 12-digit Aadhaar numbers are never requested or stored.
- **Bank Account / UPI:** Strictly limited to the **last 4 digits** or virtual payment handle.
- **Document Status:** Only checks possession of a Certificate of Vending (CoV) or Letter of Recommendation (LoR).

---

## 4. Storage & Retention
- **Volatile In-Memory Only:** Data exists solely in React memory during the active session.
- **Zero Cloud Databases:** No backend server or external database stores applicant data.
- **Immediate Purge:** Tapping the "Reset Conversation" button purges all applicant information from memory immediately.
